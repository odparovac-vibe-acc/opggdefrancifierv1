# opggdefrancifier
French is a beautiful language when its not forced upon others via https.

Browser extension (Manifest V3) that rewrites the language part of op.gg links
(`https://op.gg/pt/lol/...` → `https://op.gg/en/lol/...`) before the page loads.
Works in Chrome, Edge, Opera, Brave and Firefox from the same files.

Set the language by clicking the extension icon (default `en`).

**Install (Chromium):** `chrome://extensions` → enable Developer mode → *Load unpacked* → pick this folder.
**Install (Firefox):** `about:debugging#/runtime/this-firefox` → *Load Temporary Add-on* → pick `manifest.json`.
In Firefox, click Save in the popup once and allow access to op.gg.
